📜 FPL Rules

Sagarmatha League Competition Rules

Dashboard Manager Stats FPL Rules

🏆 Format

We start with $5 per gameweek for 19 weeks, totaling $95.

We intentionally chose a half-season format to ensure that players do not have to commit to the entire season.

Our format features prize distributions to the top three players every gameweek.

The prize distribution is based on the total number of players in the league. Since there are 30 players in the league, this first half-season prizes are distributed as follows:

  • 🥇 1st Place: $70
  • 🥈 2nd Place: $50
  • 🥉 3rd Place: $30

🥇 Winners

Weekly winners are determined using net points:

Net Points = Gross Points − Transfer Costs

The official rankings will be determined using the standings shown on the weekly table.

⚖️ Tie-Breaker Rules

If two or more managers finish with the same net points, the following tie-breakers will be applied in order:

  1. Total Bench Points
  2. Captain Points
  3. Vice-Captain Points

🎯 Triple Captain Rule

Chip bonuses are not considered when evaluating captain points for tie-breakers.

If a manager uses the Triple Captain chip, only the captain's normal score will be used when applying the captain-points tie-breaker.

🪑 Bench Boost Rule

If a manager using Bench Boost ties with a manager who did not use Bench Boost, the manager who did not use the chip will win the tie-breaker.

Exception:

If the non-Bench-Boost manager records 0 bench points, the tie-breaker will move to captain points instead.
